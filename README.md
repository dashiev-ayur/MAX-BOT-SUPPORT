# MAX Bot: логика работы системы поддержки с несколькими менеджерами

Бот для мессенджера MAX,
реализующий сценарий «один вопрос покупателя → видят все менеджеры → отвечают все, кто хочет».  

Ключевое требование: менеджеры видят, кто уже ответил и что именно. 
Покупатель видит ответы всех менеджеров.
